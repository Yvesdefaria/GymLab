# Biblioteca de entrenamiento (referencia interna)

Fuente offline estructurada para seeds y guías de GymLab.

## Orden

| # | Carpeta | Contenido |
|---|---------|-----------|
| 01 | `01-entrenamiento/` | Principios, cardio, recuperación |
| 02 | `02-por-musculo/` | Rutinas por grupo muscular |
| 03 | `03-rutinas/` | Volumen, definición, fuerza, full-body, casa, principiantes |
| 04 | `04-ejercicios/` | Catálogo por grupo |
| 05 | `05-nutricion/` | Macros, dietas, suplementos |
| 06 | `06-mujer-fitness/` | Rutinas y guías específicas |

## Uso

1. Leer markdown al ampliar seeds (`gymlab-app/src/data/seed/`).
2. En la app: solo tablas, listas y textos propios (sin narrativa larga).
3. No incluir URLs de terceros en seeds ni en commits.

## Disclaimer

Contenido informativo, no consejo médico.
