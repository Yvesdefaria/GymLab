# F132.2 — Entrenamiento · Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: `superpowers:executing-plans` (o `subagent-driven-development` si hay subagentes disponibles). Pasos con checkbox (`- [ ]`) para seguimiento.
> **Un solo escritor:** worktree `.worktrees/132.2-entrenamiento`; stagear rutas exactas; commit sin push.

**Goal:** Migrar a Nocturno Minimal las cuatro rutas de 132.2 — sesión activa (tabla B2), detalle guardado (A · volumen), calendario (A · historial) y timer (A · anillo único) — sin perder funcionalidad, datos, offline ni accesibilidad.

**Architecture:** La sesión activa reemplaza `SessionHero` + tarjetas por un header con línea de progreso, stat row y una tabla B2 de una línea por serie. Las sugerencias pasan a bandas hairline; el descanso se parte en barra fija + sheet. El detalle guardado usa héroe de volumen + stat row + bloques hairline. El calendario pasa a celdas circulares lunes-primero, intensidad por volumen y navegación solo hacia atrás. El timer usa un anillo único de 214 px y un sheet para custom.

**Tech Stack:** React 18 + TypeScript, react-router-dom, react-i18next, Tailwind v4, lucide-react, Dexie, Zustand, Recharts (no se toca), Playwright Python.

**Spec:** `gymlab-app/docs/superpowers/specs/2026-10-24-132.2-entrenamiento-design.md`
**ODD:** `odd/tasks/132.2-entrenamiento.md`

## Global Constraints

- No cambiar el modelo de datos ni la lógica de negocio de sugerencias, deload o progresión. Solo presentación.
- Un solo héroe por pantalla. En la sesión activa el héroe es el ejercicio actual; el único anillo visible es el del descanso dentro del sheet/barra.
- Dorado = progreso/aviso de coaching; verde = PR/logro/meta; rojo = error/bajar peso. **Sin amarillo** en las bandas.
- `panel-light`/`panel-chart`/`panel-hero` no se usan como contenedor principal en estas pantallas.
- RPE/RIR son columnas reales; si un ajuste está apagado, su columna no existe y la grilla se ensancha.
- `CAL` reemplaza al número de serie; las series de calentamiento no llevan RPE/RIR (`—`).
- El descanso conserva Auto, presets, sonido, vibración, pausa, reset, notificación nativa, reconciliación y detener.
- i18n es/en en espejo; default inglés. Nada de literales nuevos en componentes.
- Touch targets ≥ 44 px; foco visible; `prefers-reduced-motion`; noche/día y 6 paletas.
- `npm run build` es el typecheck real. `npm test` + e2e de las cuatro rutas antes de cerrar.
- Un commit por work unit; sin push. Review nativo antes del commit si RDD sigue encendido.

## Review Focus

- **Registro rápido:** teclear peso/reps/RPE/RIR, Enter encadena, completar serie y swipe-eliminar. Tests de `SetRow` y e2e de sesión.
- **Doble anillo:** no debe quedar `ProgressRing` de sesión visible; el descanso solo muestra anillo dentro del sheet.
- **Opciones del descanso:** Auto + presets + sonido/vibración + detener siguen accesibles desde el `⋯`.
- **Datos futuros:** el calendario no navega a meses futuros ni pinta meses vacíos como cero.
- **RPE/RIR apagados:** la tabla no deja columnas vacías; peso/reps ocupan el ancho.
- **PR/CAL/deload:** no se mezclan; `CAL` no lleva PR; deload muestra actual + sugerido tachado.
- **i18n:** todos los mensajes nuevos en es/en; el test de idioma no debe romper.
